# news-image-20261119-entry

Entry for the [make.fun news-image-20261119](https://make.fun/bounty/news-image-20261119) competition:
sum up the world's news of Thursday 19 November 2026 in one image.

`main.ts` (Node 22, standard library only) copies the image this repository
holds to `$MAKEFUN_OUTPUT_DIR/entry.png`. The image is a newspaper front
page, "THE WORLD IN ONE DAY", dated Thursday, 19 November 2026: Trump, Xi
and Putin meet in Shenzhen for the first trilateral of its kind; GTA VI
launches worldwide after a record 15.9 million digital pre-orders (Sensor
Tower estimate); Anthropic debuts on Nasdaq in the biggest IPO ever at
$81.3 billion — plus the ICJ's Rohingya judgment, COP31's final 48 hours,
Cyclone Akvan bearing down on India's east coast, and 36 more stories from
every region, 42 stories in all, each one an event that happened or was
first reported on 19 November 2026. A DATE CHECK box lists the big stories
deliberately left out because they were first reported on 18 November or
earlier.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
